# Code of Conduct

## Our Pledge

We want this project to be a welcoming place for beginners learning Python,
math, and open-source collaboration.

## Expected Behavior

- Be respectful and patient.
- Explain suggestions clearly.
- Keep feedback focused on the code, documentation, or examples.
- Remember that this project is educational.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Dismissive comments toward beginners.
- Spam or unrelated promotion.

## Enforcement

Project maintainers may remove comments, close issues, or block contributors
who repeatedly ignore these expectations.
